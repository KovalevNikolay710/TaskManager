# Дизайн-система TaskManager

Все значения — из `design/tokens.css`. В макетах и во фронтенде не используются «сырые» цвета, размеры и отступы: только `var(--...)`.
Макеты экранов лежат в `design/screens/`, у каждого — спецификация `<screen>.md`.
Эталонная вёрстка компонентов — `design/components.css` (классы из этого документа; её подключают макеты, фронтенд использует как референс). Блок `.mock-panel` в ней — только для переключения состояний в макетах, во фронтенд не переносится.

## Принципы

1. **Приоритет — главный порядок.** Любой список задач отсортирован по `Priority` по убыванию. Порядок — основной сигнал; цвет индикатора — дополнительный. Приоритет не показывается крупным текстом.
2. **Спокойный интерфейс.** Один акцентный цвет (`--color-accent`) — только для действий и активной навигации. Красный/янтарный — только для приоритета и дедлайнов.
3. **Mobile-first.** База 360–430px. С 960px — боковая навигация, контент центрирован, `max-width: var(--layout-max-width)`.
4. **Всё нажимаемое ≥ 44px** (`--size-touch`), даже если видимая часть меньше (чекбокс 22px внутри зоны 44px).
5. **Каждый экран имеет состояния**: загрузка (skeleton), пусто (с подсказкой и действием), ошибка (с кнопкой «Повторить»).
6. **Русский язык, человеческие даты** — см. «Форматы».
7. **Контраст ≥ WCAG AA**: текст 4.5:1, графические элементы UI 3:1. Цвет никогда не единственный носитель смысла (у приоритета есть число, у дедлайна — текст).

## Раскладка

### AppShell
Каркас каждого экрана.

- Мобильный (< 960px): `AppHeader` сверху (прилипает при скролле), контент, `BottomNav` снизу (fixed). Контенту — нижний отступ `calc(var(--size-bottom-nav) + env(safe-area-inset-bottom) + var(--space-4))`.
- Десктоп (≥ 960px): `SideNav` слева шириной `--size-side-nav`, контент справа центрирован с `max-width: var(--layout-max-width)`, `BottomNav` скрыт.
- Фон страницы `--color-bg`, горизонтальные поля `--space-4` (мобильный) / `--space-8` (десктоп).

### AppHeader
- Слева: заголовок экрана (`--text-xl`, semibold; на десктопе `--text-2xl`) и под ним подзаголовок (`--text-sm`, `--color-text-muted`), например «12 активных · 3 выполнено».
- Справа: `AvatarButton` (профиль). На десктопе аватар переезжает в низ `SideNav`, в шапке не дублируется.
- Фон `--color-bg`; при прокрутке появляется нижняя граница `--color-border`.

### BottomNav (мобильный)
- Два пункта в порядке: **«День»** (иконка календаря) и **«Все задачи»** (иконка списка).
- Высота `--size-bottom-nav` + `env(safe-area-inset-bottom)`, фон `--color-surface-raised`, тень `--shadow-nav`.
- Пункт: иконка 24px над подписью `--text-xs`/medium, вся ширина половины экрана — зона нажатия.
- Активный: иконка и подпись `--color-accent`, над иконкой pill-подложка `--color-accent-soft` (56×32, `--radius-full`). Неактивный: `--color-text-muted`.
- Семантика: `<nav aria-label="Основная навигация">`, активный пункт `aria-current="page"`.

### SideNav (десктоп)
- Вертикальная панель на всю высоту, фон `--color-surface`, правая граница `--color-border`.
- Сверху — название «TaskManager» (`--text-lg`, semibold), затем те же два пункта (иконка + подпись в строку, высота 44px, `--radius-md`; активный — фон `--color-accent-soft`, текст `--color-accent`).
- Внизу — блок профиля: `AvatarButton` + имя пользователя.

## Компоненты

### AvatarButton
Круглая кнопка 36px (`--size-avatar`, зона нажатия 44px), фон `--color-accent-soft`, инициалы `--color-accent`, `--text-sm` semibold. Ведёт на экран «Профиль». `aria-label="Профиль"`.
Пока пользователей нет — инициалы-заглушка «Я».

### SearchField
- Высота 44px, фон `--color-surface-sunken`, `--radius-md`, без обводки; иконка лупы слева (`--color-text-muted`), placeholder «Поиск задач».
- При вводе справа появляется кнопка очистки (×, зона 44px).
- Фокус: обводка 2px `--color-focus`.
- Поиск клиентский, без кнопки «Найти», срабатывает при вводе (debounce 150 мс).

### Button
| Вариант | Вид | Когда |
|---|---|---|
| primary | фон `--color-accent`, текст `--color-text-inverse` | главное действие экрана («Спланировать день») |
| secondary | фон `--color-surface`, обводка `--color-border`, текст `--color-text` | «Повторить», второстепенные |
| ghost | без фона, текст `--color-accent` | действия в строке, «Показать выполненные» |
| icon | 44×44, без фона, иконка `--color-text-muted` | стрелки переключения даты, очистка поиска |

Высота 44px, `--radius-md`, `--text-md` medium, горизонтальный padding `--space-4`. Hover — `--color-accent-hover` (primary) / `--color-surface-sunken` (остальные). Disabled — opacity 0.5. Фокус — `outline: 2px solid var(--color-focus); outline-offset: 2px`.

### Fab (кнопка «Добавить задачу»)
Круглая 56px, `--color-accent`, иконка «+» `--color-text-inverse`, `--shadow-lg`. Мобильный: справа над `BottomNav` (`--space-4` от края). Десктоп: вместо Fab — primary-кнопка «Новая задача» в `AppHeader`. `aria-label="Добавить задачу"`. Экран создания задачи будет отдельным макетом.

### Checkbox
- Видимый квадрат 22px (`--size-checkbox`), `--radius-sm`, обводка 2px `--color-border-strong`; зона нажатия 44×44.
- Отмечен: фон `--color-success`, белая галочка.
- Промежуточное (запрос в процессе): обводка `--color-success`, внутри спиннер/пульсация; повторные нажатия игнорируются.
- Disabled: курсор `not-allowed`, подсказка `title`. Сейчас так выглядят чекбоксы выполненных задач — бэкенд не умеет возвращать задачу в работу.
- `role="checkbox"`/`<input type="checkbox">`, подпись — название задачи (`aria-labelledby`).

### PriorityIndicator
Показывает приоритет задачи компактно, двумя элементами:

1. **Полоска** слева на карточке задачи: ширина `--size-priority-bar`, высота — вся карточка, цвет по уровню.
2. **Чип с числом** справа в мета-строке: `--text-xs` medium, моноширинные цифры (`font-variant-numeric: tabular-nums`), padding `2px 6px`, `--radius-sm`, фон `--color-priority-<level>-soft`, текст `--color-priority-<level>-text`. Перед числом — маленькая иконка-молния или точка 6px цвета уровня. `aria-label="Приоритет 7,5, высокий"`.

**Уровни** считаются на клиенте относительно максимального `Priority` среди **активных** задач текущего набора (экран/день):

| Уровень | Условие | Токены |
|---|---|---|
| high | `Priority ≥ 0.6 × max` | `--color-priority-high*` |
| mid | `0.25 × max ≤ Priority < 0.6 × max` | `--color-priority-mid*` |
| low | `Priority < 0.25 × max` или `max = 0` | `--color-priority-low*` |

Почему относительно: `Pt = Pg * Te / Tl * %in` не имеет фиксированного масштаба (зависит от приоритетов групп пользователя), абсолютные пороги были бы произвольными.

**Число**: `Priority`, округлённое до одного знака, запятая как разделитель («7,5»). Если `0 < Priority < 0.1` — «<0,1».
**Выполненные задачи**: индикатор нейтральный — полоска `--color-border`, чип скрыт.

### TaskRow (карточка задачи)
Основной элемент списков.

```
┌▌─────────────────────────────────────────────┐
│▌ [☐]  Подготовить отчёт по ТИПИС              │
│▌      ⏱ 2:30 · 📅 завтра, 10:00 · 40%  ⚡7,5 │
└▌─────────────────────────────────────────────┘
```

- Контейнер: фон `--color-surface`, padding `--space-3` `--space-4`, слева `PriorityIndicator`-полоска.
- Два режима размещения: внутри `GroupSection` — строки общей карточки с разделителями; отдельным списком (`.task-list` > `.task-card`) — самостоятельные карточки `--radius-md`, `--shadow-sm`, промежуток `--space-2`.
- Колонка 1: `Checkbox`.
- Колонка 2:
  - Название — `--text-md` medium, `--color-text`, до 2 строк, затем многоточие.
  - Мета-строка — `--text-sm`, `--color-text-muted`, элементы через « · »:
    - время на выполнение (`TimeForExecution`) — иконка часов + длительность в формате `Ч:ММ` («2:30», «0:45»), `aria-label="2 часа 30 минут"`;
    - дедлайн (`DeadLine`) — `DeadlineLabel`;
    - прогресс (`PercentOfCompleting`) — показывается, только если 0 < % < 100: «40%».
    - на экранах, где задачи из разных групп идут одним списком (экран «День»), первым фактом идёт название группы с иконкой папки.
  - Справа в мета-строке (прижат вправо) — чип `PriorityIndicator`.
- Нажатие на карточку (вне чекбокса) — открывает задачу (экран «Задача», будет отдельным макетом). Hover на десктопе — фон `--color-surface-sunken`.
- **Выполненная**: название `--color-text-muted` и зачёркнуто, мета-строка скрывается кроме дедлайна, opacity всей карточки 0.7, полоска нейтральная. Уходит вниз своей группы.
- **Совпадение поиска**: совпавший фрагмент названия — `<mark>` с фоном `--color-accent-soft`, цвет текста наследуется.

### DeadlineLabel
Текст дедлайна по правилам «Форматы». Цвет:
- просрочен (`DeadLine < now`) — `--color-danger`, medium, текст «просрочено на 3 ч»;
- меньше 24 часов — `--color-warning`, medium;
- иначе — `--color-text-muted`.
Всегда с иконкой календаря/флажка — цвет не единственный сигнал.

### GroupSection
Секция экрана «Все задачи».

- Заголовок-строка (кнопка сворачивания, высота ≥ 44px):
  - название группы (`Group.Name`) — `--text-lg` semibold;
  - бейдж приоритета группы «×3» (`Group.GroupPriority`) — `--text-xs`, `--color-text-muted`, обводка `--color-border`, `--radius-full`; `title="Приоритет группы 3"`. Это множитель `Pg` в формуле, поэтому «×»;
  - счётчик справа «2 / 5» (выполнено / всего) — `--text-sm`, `--color-text-muted`;
  - шеврон сворачивания справа. Состояние свёрнутости хранится в `localStorage`.
- Тело: карточка `--color-surface`, `--radius-lg`, `--shadow-sm`; задачи внутри — `TaskRow` без собственного фона, разделённые линией `--color-border` (отступ слева на ширину чекбокса).
- Между секциями `--space-6`.
- Порядок секций: по `GroupPriority` по убыванию, затем по имени; секция «Без группы» — последней.
- Если в группе больше 3 выполненных, выполненные сворачиваются в строку «Выполнено: 5 — показать» (ghost-кнопка).

### SummaryStat
Плитка сводки на экране дня: значение `--text-2xl` semibold (tabular-nums) + подпись `--text-xs` `--color-text-muted`. Фон `--color-surface`, `--radius-lg`, padding `--space-4`. Располагаются сеткой 3 в ряд (на узких < 360px — 2 + 1).

### ProgressBar
Трек высотой 8px, `--radius-full`, фон `--color-surface-sunken`; заполнение `--color-accent` (или `--color-danger`, если превышение 100%). Сверху подпись слева и значение справа (`--text-sm`). `role="progressbar"` с `aria-valuenow/min/max`.

### DateSwitcher
Строка: icon-кнопка «‹» — дата — icon-кнопка «›». Дата: «Сегодня, 24 сентября» (`--text-md` semibold). Под ней — день недели `--text-sm` muted, если дата не сегодня/завтра/вчера. Стрелки переключают на предыдущий/следующий существующий `Day`; если его нет — стрелка disabled.

### PlanForm
Форма параметров плана дня; используется в пустом состоянии экрана «День» и в `Sheet` «Изменить план».
- **Stepper** «Сколько задач»: `[−] N [+]`, фон `--color-surface-sunken`, `--radius-md`, кнопки 44×44, значение `--text-lg` semibold. Диапазон 1–20, на границах кнопка disabled. `role="group"`, значение в `<output aria-live="polite">`.
- **TimeInput** «Сколько времени» — см. ниже; под ним быстрые кнопки-пресеты.
- **Пресеты времени**: чипы «2:00», «4:00», «6:00», «8:00» — обычные кнопки, нажатие подставляет значение в `TimeInput`. Чип, совпадающий с текущим значением поля, подсвечен (`aria-pressed="true"`: фон `--color-accent-soft`, текст и обводка 1.5px `--color-accent`). Чип: высота 36px (зона 44px), `--radius-full`, обводка `--color-border`.
- Подписи полей — `--text-sm` medium, подсказки — `--text-xs` muted.

### TimeInput
Поле ввода длительности в формате `Ч:ММ`; в API уходит целым числом минут.
- Вид: высота 44px, ширина ~120px, фон `--color-surface-sunken`, `--radius-md`, текст `--text-lg` semibold, tabular-nums, по центру; placeholder «0:00»; справа мелкая подпись «ч:мм» `--text-xs` muted. Фокус — обводка 2px `--color-focus`.
- `inputmode="numeric"`, `aria-label` поля — подпись поля, `aria-describedby` — подсказка/ошибка.
- Разбор ввода: «2:30» → 150; «2» → 120 (целые часы); «230» без двоеточия → 2:30 (последние две цифры — минуты). Минуты 00–59. После потери фокуса значение нормализуется к виду `Ч:ММ` («2:5» → «2:05»).
- Ограничения для плана дня: от 0:15 до 16:00. Ошибка — обводка и текст подсказки `--color-danger`: «Введите время в формате ч:мм, например 2:30» / «Не больше 16:00», primary-кнопка формы disabled.

### Sheet
Модальная панель. Мобильный: выезжает снизу, `--radius-lg` сверху, «ручка» 36×4 `--color-border-strong`, фон `--color-surface-raised`. Десктоп: диалог 420px по центру. Подложка `rgba(10,12,20,.45)`. Заголовок `--text-lg` semibold + icon-кнопка «×». Внизу две кнопки поровну: secondary «Отмена» и primary-действие. Закрывается по подложке, «×», Esc; фокус заперт внутри, при закрытии возвращается на кнопку-вызов. `role="dialog" aria-modal="true"`.

### Badge
Небольшая pill-метка: `--text-xs` medium, фон `--color-surface-sunken`, текст `--color-text-muted`, `--radius-full`, padding `2px 8px`. Для статусов вроде «Прошедший день».

### SectionTitle
Заголовок списка внутри экрана: слева `h2` `--text-lg` semibold, справа ghost-кнопка или подпись `--text-sm` muted.

### Skeleton
Прямоугольники `--color-surface-sunken`, `--radius-sm`, с пульсацией opacity 1 → 0.5 (1.2 с). Повторяют форму реального контента (заголовок группы + 3 строки задач). `aria-busy="true"` на контейнере. При `prefers-reduced-motion` — без анимации.

### EmptyState
По центру области: иконка 48px в круге `--color-accent-soft`, заголовок `--text-lg` semibold, текст-подсказка `--text-md` muted (max 32ch), primary-кнопка действия. Отступы `--space-12` сверху.

### ErrorState
Как EmptyState, но иконка в круге `--color-danger-soft` цвета `--color-danger`, заголовок «Не удалось загрузить задачи», текст ошибки из `{"error": "..."}` мелко muted, secondary-кнопка «Повторить».

### Toast
Снизу по центру над `BottomNav` (десктоп — снизу справа), фон `--color-text`, текст `--color-bg`, `--radius-md`, `--shadow-lg`, 4 с. Может содержать ghost-действие («Повторить»). `role="status"`. Используется для ошибок фоновых действий (не удалось отметить задачу).

## Форматы

| Что | Правило | Примеры |
|---|---|---|
| Длительность (`Task.TimeForExecution`, `Day.TimeForTasks`, хранятся в минутах) | показ и ввод — `Ч:ММ`: часы без ведущего нуля, минуты всегда двумя цифрами. Для скринридеров — словами | «0:45», «2:00», «2:30», «7:00»; `aria-label="2 часа 30 минут"` |
| Дедлайн в будущем | сегодня → «сегодня, ЧЧ:ММ»; завтра → «завтра, ЧЧ:ММ»; 2–6 дней → «через N дней»; дальше → «12 окт» (с годом, если не текущий) | «сегодня, 18:00», «через 3 дня» |
| Дедлайн прошёл | «просрочено на N мин/ч/дн» (это относительное время, а не длительность — формат `Ч:ММ` здесь не применяется) | «просрочено на 2 ч» |
| Дата дня | «Сегодня, 24 сентября» / «Завтра, 25 сентября» / «Пятница, 26 сентября» | |
| Приоритет | 1 знак после запятой, запятая | «7,5», «0,4» |
| Количество | с согласованием: «1 задача», «3 задачи», «5 задач» | |

Время — в локальном часовом поясе браузера; API отдаёт RFC3339.

## Иконки
Линейные 24px, stroke 1.75, `currentColor` (набор уровня Lucide/Feather). Используемые: `calendar` (День), `list-checks` (Все задачи), `search`, `x`, `plus`, `clock` (длительность), `flag` (дедлайн), `zap` (приоритет), `chevron-down/left/right`, `alert-triangle`, `refresh-cw`, `inbox` (пусто).
