# Дизайн-система TaskManager

Все значения — из `design/tokens.css`. В макетах и во фронтенде не используются «сырые» цвета, размеры и отступы: только `var(--...)`.
Макеты экранов лежат в `design/screens/`, у каждого — спецификация `<screen>.md`.
Эталонная вёрстка компонентов — `design/components.css` (классы из этого документа; её подключают макеты, фронтенд использует как референс). Блок `.mock-panel` в ней — только для переключения состояний в макетах, во фронтенд не переносится.

## Принципы

1. **Приоритет — главный порядок.** Любой список задач отсортирован по `Priority` по убыванию. Порядок — основной сигнал; цвет индикатора — дополнительный. Приоритет не показывается крупным текстом.
2. **Спокойный интерфейс.** Один акцентный цвет (`--color-accent`) — только для действий и активной навигации. Красный/янтарный — только для приоритета и дедлайнов. Шкала веса `--color-weight-1…10` — только для веса группы и того, что из него следует (ступени лесенки, секторы плана дня); у задачи она проявляется только на экране «День».
3. **Mobile-first.** База 360–430px. С 960px — боковая навигация, контент центрирован, `max-width: var(--layout-max-width)`.
4. **Всё нажимаемое ≥ 44px** (`--size-touch`), даже если видимая часть меньше (чекбокс 22px внутри зоны 44px).
5. **Каждый экран имеет состояния**: загрузка (skeleton), пусто (с подсказкой и действием), ошибка (с кнопкой «Повторить»).
6. **Русский язык, человеческие даты** — см. «Форматы».
7. **Контраст ≥ WCAG AA**: текст 4.5:1, графические элементы UI 3:1. Цвет никогда не единственный носитель смысла (у приоритета есть число, у дедлайна — текст, у веса — «×N»).

## Шкала веса ×1…×10

Вес группы (`Group.GroupPriority`, множитель `Pg`) — 10 ступеней, у каждой свой цвет: от спокойного сине-серого (×1) через бирюзу и зелень к янтарю, красному и малиновому (×10). Чем теплее и насыщеннее цвет, тем важнее группа.

| Токен | Для чего | Контраст |
|---|---|---|
| `--color-weight-N` | графика: ступень лесенки, сектор диаграммы дня, точка в чипе, полоска задачи в плане дня, обводка бейджа | ≥ 3:1 на `--color-surface` в обеих темах. На `--color-bg` не используется (у ×7 там 3.2:1 → граница) |
| `--color-weight-N-soft` | фон бейджа, плитки, выбранного чипа, карточки группы на лесенке | — |
| `--color-weight-N-text` | «×N» и текст на `-soft` | ≥ 5.8:1 на `-soft`, ≥ 6.6:1 на surface |

- Во вёрстке используется утилита `.w-N`: она задаёт `--w`, `--w-soft`, `--w-text`, а компоненты читают только эти три переменные. Во фронтенде — `weightClass(n)` с ограничением `n` до 1–10 (у старых групп вес может быть больше 10 — показываем как ×10).
- Текст на сплошной `--color-weight-N` не кладём: у ×9–×10 белый и тёмный текст не проходят AA одновременно в обеих темах.
- Число «×N» всегда рядом с цветом.
- «Без группы» = вес 1, но в `GroupPicker` и на лесенке показывается нейтрально (`--color-border-strong`), чтобы отличаться от настоящей группы ×1.
- Не путать со шкалой **приоритета задачи** (`--color-priority-low|mid|high`, относительная, три уровня): вес — свойство группы и задаётся пользователем, приоритет — результат формулы.

## Раскладка

### AppShell
Каркас каждого экрана.

- Мобильный (< 960px): `AppHeader` сверху (прилипает при скролле), контент, `BottomNav` снизу (fixed). Контенту — нижний отступ `calc(var(--size-bottom-nav) + env(safe-area-inset-bottom) + var(--space-4))`.
- Десктоп (≥ 960px): `SideNav` слева шириной `--size-side-nav`, контент справа центрирован с `max-width: var(--layout-max-width)`, `BottomNav` скрыт.
- Фон страницы `--color-bg`, горизонтальные поля `--space-4` (мобильный) / `--space-8` (десктоп).

### Карта экранов и навигация

| Маршрут | Экран | Шапка | BottomNav (мобильный) | Активный пункт SideNav |
|---|---|---|---|---|
| `/day` | Задачи на день | `AppHeader` | да, «День» | День |
| `/all-tasks` | Все задачи | `AppHeader` (+ кнопка «Группы» на мобильном) | да, «Все задачи» | Все задачи |
| `/groups` | Группы | `PageHeader` (назад → `/all-tasks`) | да, «Все задачи» | Группы |
| `/tasks/new` | Новая задача | `PageHeader` | **нет** — внизу `ActionBar` | Все задачи |
| `/tasks/:taskId` | Задача | `PageHeader` | **нет** — внизу `ActionBar` при изменениях | Все задачи |
| `/profile` | Профиль и уведомления (`design/screens/profile.md`) | `AppHeader` без `AvatarButton` | да, без активного | блок профиля внизу (`aria-current`) |
| `?quick=1` на `/all-tasks` и `/day` | `QuickAddSheet` «Быстрая задача» поверх экрана (`design/screens/quick-add.md`) | — | закрыт подложкой | как у экрана под листом |

Экраны-формы (`/tasks/new`, `/tasks/:taskId`) — «вложенные»: на мобильном без `BottomNav`, чтобы липкая панель сохранения и экранная клавиатура не спорили за низ экрана. Выход — кнопкой «назад» в `PageHeader`.
«Группы» — раздел внутри «Все задачи» (группы — это структура именно этого экрана), поэтому `BottomNav` остаётся с активным «Все задачи», а в `BottomNav` третьего пункта нет. На десктопе места достаточно — «Группы» отдельным пунктом `SideNav`.

### AppHeader
- Слева: заголовок экрана (`--text-xl`, semibold; на десктопе `--text-2xl`) и под ним подзаголовок (`--text-sm`, `--color-text-muted`), например «12 активных · 3 выполнено».
- Справа: `AvatarButton` (профиль). На десктопе аватар переезжает в низ `SideNav`, в шапке не дублируется. На самом экране «Профиль» аватара нет.
- Десктоп, «Все задачи» и «День»: primary-кнопка «Новая задача» — открывает `QuickAddSheet` (не переход на `/tasks/new`).
- На «Все задачи» перед аватаром — icon-кнопка «Группы» (иконка `folder`, цвет `--color-text`, `aria-label="Группы"`, ведёт на `/groups`). На десктопе скрыта — там есть пункт `SideNav`.
- Фон `--color-bg`; при прокрутке появляется нижняя граница `--color-border`.

### PageHeader (вложенные экраны)
Шапка экранов «Задача», «Новая задача», «Группы».
- Строка высотой ≥ 60px: icon-кнопка «назад» (`chevron-left`, цвет `--color-text`, `aria-label="Назад"`), заголовок `--text-lg` semibold в одну строку с многоточием, справа — необязательные действия (ghost-кнопки).
- Липкая, фон `--color-bg`; при прокрутке — нижняя граница `--color-border` (класс `page-header--scrolled`). Десктоп: заголовок `--text-2xl`, отступ сверху `--space-6`.
- «Назад»: если в истории есть предыдущая страница приложения — `history.back()`, иначе — родительский экран (`/all-tasks`). Если на экране есть несохранённые изменения — сначала `ConfirmSheet` «Выйти без сохранения?».
- Аватар в `PageHeader` не показывается.

### BottomNav (мобильный)
- Два пункта в порядке: **«День»** (иконка календаря) и **«Все задачи»** (иконка списка).
- Высота `--size-bottom-nav` + `env(safe-area-inset-bottom)`, фон `--color-surface-raised`, тень `--shadow-nav`.
- Пункт: иконка 24px над подписью `--text-xs`/medium, вся ширина половины экрана — зона нажатия.
- Активный: иконка и подпись `--color-accent`, над иконкой pill-подложка `--color-accent-soft` (56×32, `--radius-full`). Неактивный: `--color-text-muted`.
- Семантика: `<nav aria-label="Основная навигация">`, активный пункт `aria-current="page"`.

### SideNav (десктоп)
- Вертикальная панель на всю высоту, фон `--color-surface`, правая граница `--color-border`.
- Сверху — название «TaskManager» (`--text-lg`, semibold), затем пункты «День», «Все задачи», «Группы» (иконка `folder`) — иконка + подпись в строку, высота 44px, `--radius-md`; активный — фон `--color-accent-soft`, текст `--color-accent`.
- Внизу — блок профиля: `AvatarButton` + имя пользователя.

## Компоненты

### AvatarButton
Круглая кнопка 36px (`--size-avatar`, зона нажатия 44px), фон `--color-accent-soft`, инициалы `--color-accent`, `--text-sm` semibold. Ведёт на экран «Профиль». `aria-label="Профиль"`.
Пока пользователей нет — инициалы-заглушка «Я».

### SearchField
- Высота 44px, фон `--color-surface-sunken`, `--radius-md`, без обводки; иконка лупы слева (`--color-text-muted`), placeholder «Поиск задач».
- При вводе справа появляется кнопка очистки (×, зона 44px).
- Фокус: обводка 2px `--color-focus`.
- Поиск клиентский, без кнопки «Найти», срабатывает при вводе (debounce 150 мс).

### Button
| Вариант | Вид | Когда |
|---|---|---|
| primary | фон `--color-accent`, текст `--color-text-inverse` | главное действие экрана («Спланировать день») |
| secondary | фон `--color-surface`, обводка `--color-border`, текст `--color-text` | «Повторить», второстепенные |
| ghost | без фона, текст `--color-accent` | действия в строке, «Показать выполненные» |
| icon | 44×44, без фона, иконка `--color-text-muted` | стрелки переключения даты, очистка поиска |
| danger | фон `--color-danger`, текст `--color-text-inverse`, hover `--color-danger-hover` | только подтверждение необратимого действия в `ConfirmSheet` («Удалить») |
| danger-ghost | без фона, текст `--color-danger`, hover — фон `--color-danger-soft` | вход в удаление («Удалить задачу», «Удалить группу»), всегда внизу экрана/Sheet, отдельно от основных действий |

Модификаторы: `btn--block` — на всю ширину. **Загрузка**: кнопка `disabled` + `aria-busy="true"`, слева `spinner` (16px, обводка 2px `currentColor`), текст меняется на процесс («Создаём…», «Сохраняем…», «Удаляем…»); ширина кнопки не прыгает.

Высота 44px, `--radius-md`, `--text-md` medium, горизонтальный padding `--space-4`. Hover — `--color-accent-hover` (primary) / `--color-surface-sunken` (остальные). Disabled — opacity 0.5. Фокус — `outline: 2px solid var(--color-focus); outline-offset: 2px`.

### Fab (кнопка «Добавить задачу»)
Круглая 56px, `--color-accent`, иконка «+» `--color-text-inverse`, `--shadow-lg`. Мобильный: справа над `BottomNav` (`--space-4` от края) на экранах **«Все задачи» и «День»**. Десктоп: вместо Fab — primary-кнопка «Новая задача» в `AppHeader` и клавиша `N`. `aria-label="Добавить задачу"`, `aria-haspopup="dialog"`.
**Открывает `QuickAddSheet`** («Быстрая задача», `design/screens/quick-add.md`), а не `/tasks/new`. Полная форма доступна из листа по «Подробнее» с переносом введённого. После закрытия листа фокус возвращается на Fab.

### Checkbox
- Видимый квадрат 22px (`--size-checkbox`), `--radius-sm`, обводка 2px `--color-border-strong`; зона нажатия 44×44.
- Отмечен: фон `--color-success`, белая галочка.
- Промежуточное (запрос в процессе): обводка `--color-success`, внутри спиннер/пульсация; повторные нажатия игнорируются.
- Disabled: курсор `not-allowed`, подсказка `title`. (Раньше так выглядели чекбоксы выполненных задач; теперь `POST /api/tasks/update/:id` принимает `status: 1`, и снятие отметки возвращает задачу в работу.)
- `role="checkbox"`/`<input type="checkbox">`, подпись — название задачи (`aria-labelledby`).

### PriorityIndicator
Показывает приоритет задачи компактно, двумя элементами:

1. **Полоска** слева на карточке задачи: ширина `--size-priority-bar`, высота — вся карточка, цвет по уровню.
2. **Чип с числом** справа в мета-строке: `--text-xs` medium, моноширинные цифры (`font-variant-numeric: tabular-nums`), padding `2px 6px`, `--radius-sm`, фон `--color-priority-<level>-soft`, текст `--color-priority-<level>-text`. Перед числом — маленькая иконка-молния или точка 6px цвета уровня. `aria-label="Приоритет 7,5, высокий"`.

**Уровни** считаются на клиенте относительно максимального `Priority` среди **активных** задач текущего набора (экран/день):

| Уровень | Условие | Токены |
|---|---|---|
| high | `Priority ≥ 0.6 × max` | `--color-priority-high*` |
| mid | `0.25 × max ≤ Priority < 0.6 × max` | `--color-priority-mid*` |
| low | `Priority < 0.25 × max` или `max = 0` | `--color-priority-low*` |

Почему относительно: `Pt = Pg * Te / Tl * %in` не имеет фиксированного масштаба (зависит от приоритетов групп пользователя), абсолютные пороги были бы произвольными.

**Число**: `Priority`, округлённое до одного знака, запятая как разделитель («7,5»). Если `0 < Priority < 0.1` — «<0,1».
**Выполненные задачи**: индикатор нейтральный — полоска `--color-border`, чип скрыт.

### TaskRow (карточка задачи)
Основной элемент списков.

```
┌▌─────────────────────────────────────────────┐
│▌ [☐]  Подготовить отчёт по ТИПИС              │
│▌      ⏱ 2:30 · 📅 завтра, 10:00 · 40%  ⚡7,5 │
└▌─────────────────────────────────────────────┘
```

- Контейнер: фон `--color-surface`, padding `--space-3` `--space-4`, слева `PriorityIndicator`-полоска.
- Два режима размещения: внутри `GroupSection` — строки общей карточки с разделителями; отдельным списком (`.task-list` > `.task-card`) — самостоятельные карточки `--radius-md`, `--shadow-sm`, промежуток `--space-2`.
- Колонка 1: `Checkbox`.
- Колонка 2:
  - Название — `--text-md` medium, `--color-text`, до 2 строк, затем многоточие.
  - Мета-строка — `--text-sm`, `--color-text-muted`, элементы через « · »:
    - время на выполнение (`TimeForExecution`) — иконка часов + длительность в формате `Ч:ММ` («2:30», «0:45»), `aria-label="2 часа 30 минут"`;
    - дедлайн (`DeadLine`) — `DeadlineLabel`;
    - прогресс (`PercentOfCompleting`) — показывается, только если 0 < % < 100: «40%».
    - на экранах, где задачи из разных групп идут одним списком (экран «День»), первым фактом идёт название группы с иконкой папки.
  - Справа в мета-строке (прижат вправо) — чип `PriorityIndicator`.
- Нажатие на карточку (вне чекбокса) — открывает задачу `/tasks/:TaskId` (`design/screens/task.html`). Hover на десктопе — фон `--color-surface-sunken`.
- **Выполненная**: название `--color-text-muted` и зачёркнуто, мета-строка скрывается кроме дедлайна, opacity всей карточки 0.7, полоска нейтральная. Уходит вниз своей группы.
- **Совпадение поиска**: совпавший фрагмент названия — `<mark>` с фоном `--color-accent-soft`, цвет текста наследуется.
- **Вариант «слот дня»** (`task--slot` + `.w-N`, только экран «День»):
  - полоска слева — цвет сектора диаграммы (`--w` по `Task.GroupPriorty`), а не уровень приоритета: строка служит легендой к `DayChart`. У выполненной — `--color-day-done`. Приоритет по-прежнему передают порядок и чип;
  - справа от названия (`task__top`) — выделенное на сегодня время `SlotTime`: **«1:25»** (`--text-md` semibold, tabular-nums) + «сегодня» (`--text-xs` muted); для скринридера «В плане на сегодня: 1 час 25 минут». У выполненной задачи время остаётся, но muted;
  - в мета-строке время на выполнение подписано «всего 3:00», чтобы не путать его со «сегодня»;
  - подсветка из диаграммы: у списка класс `task-list--focus` (прочие карточки opacity 0.45), у выбранной карточки `task-card--active` (обводка 2px `--w`, `--shadow-md`).

### DeadlineLabel
Текст дедлайна по правилам «Форматы». Цвет:
- просрочен (`DeadLine < now`) — `--color-danger`, medium, текст «просрочено на 3 ч»;
- меньше 24 часов — `--color-warning`, medium;
- иначе — `--color-text-muted`.
Всегда с иконкой календаря/флажка — цвет не единственный сигнал.

### GroupSection
Секция экрана «Все задачи».

- Заголовок-строка (кнопка сворачивания, высота ≥ 44px):
  - название группы (`Group.Name`) — `--text-lg` semibold;
  - бейдж веса группы «×3» (`Group.GroupPriority`) — `--text-xs` medium, `--radius-full`, в цветах ступени: фон `--w-soft`, обводка 1px `--w`, текст `--w-text` (класс `.w-N`); `title="Приоритет группы 3"`. Это множитель `Pg` в формуле, поэтому «×»;
  - счётчик справа «2 / 5» (выполнено / всего) — `--text-sm`, `--color-text-muted`;
  - шеврон сворачивания справа. Состояние свёрнутости хранится в `localStorage`.
- Тело: карточка `--color-surface`, `--radius-lg`, `--shadow-sm`; задачи внутри — `TaskRow` без собственного фона, разделённые линией `--color-border` (отступ слева на ширину чекбокса).
- Между секциями `--space-6`.
- Порядок секций: по `GroupPriority` по убыванию, затем по имени; секция «Без группы» — последней.
- Если в группе больше 3 выполненных, выполненные сворачиваются в строку «Выполнено: 5 — показать» (ghost-кнопка).

### DateSwitcher
Строка: icon-кнопка «‹» — дата — icon-кнопка «›». Дата: «Сегодня, 24 сентября» (`--text-md` semibold). Под ней — день недели `--text-sm` muted, если дата не сегодня/завтра/вчера. Стрелки переключают на предыдущий/следующий существующий `Day`; если его нет — стрелка disabled.

### DayChart
Кольцевая диаграмма плана дня (экран «День»): какую часть времени дня занимает каждая задача.
- Карточка: фон `--color-surface`, `--radius-lg`, `--shadow-sm`, padding `--space-4` (десктоп `--space-6`). Мобильный: кольцо по центру, под ним сводка. Десктоп (≥ 960px): кольцо слева, сводка справа, подсказка (`day-chart__note`) снизу на всю ширину.
- **Кольцо** (SVG, `viewBox 0 0 240 240`, внешний радиус 112, внутренний 74): диаметр `--size-day-chart` (220px), на десктопе 240px. Трек — `--color-day-free`. 100% кольца = `Day.TimeForTasks`.
- **Сектор** = слот задачи: угол `Minutes / TimeForTasks × 360°`, от 12 часов по часовой стрелке в порядке списка (активные по `Priority` ↓, затем выполненные, затем «Свободно»). Заливка `--w` по весу группы задачи; выполненная — `--color-day-done`; «Свободно» — `--color-day-free` (сливается с треком: это «пустая» часть дня). Между секторами зазор — обводка 2px `--color-surface`. Подписей на кольце нет.
- **Центр** (`aria-live="polite"`): по умолчанию «4:30» (`--text-2xl` semibold) и «осталось из 6:00» (`--text-xs` muted). При подсветке сектора — название задачи (`--text-sm` medium, до 2 строк), её время «1:25» (`--text-xl`), подпись «сегодня · Учёба» / «выполнено» / «свободно».
- **Подсветка**: наведение на сектор или строку, фокус на строке, тап по сектору (закрепляет; повторный тап или тап вне кольца снимает). Остальные секторы — opacity 0.3, выбранный — `scale(1.04)` (без масштаба при `prefers-reduced-motion`); в списке — см. `TaskRow` «слот дня».
- **Сводка** (`day-chart__summary`, `--text-sm`): строки с цветным квадратиком 12px и значением справа (semibold, tabular-nums): «В работе: 6 задач — 4:30» (квадратик — мини-конус из цветов шкалы), «Выполнено: 1 — 1:30» (`--color-day-done`), «Свободно — 2:55» (`--color-day-free` с обводкой), «⚡ Приоритет дня (осталось) — 26,9» (muted). Нулевые строки (кроме «В работе») не показываются.
- **Подсказка** (`day-chart__note`, над ней разделитель): «Ещё N задач не в плане…» + ghost «Изменить план» или «Всё, что нужно сегодня, помещается. Свободные 2:55 — на новое дело или отдых».
- Доступность: `<svg role="img" aria-label="План на 6:00: <задача> 1 час 25 минут; …; свободно 2 часа 55 минут">`, секторы не фокусируются — полноценная текстовая замена диаграммы — список задач под ней.
- Skeleton: круг `--size-day-chart` + две полосы.

### PlanForm
Форма параметров плана дня; используется в пустом состоянии экрана «День» и в `Sheet` «Изменить план». Единственный параметр — время: количество задач не выбирается, приложение само делит время между всеми подходящими задачами (алгоритм — `design/screens/day.md`).
- **TimeInput** «Время на день» — см. ниже; под ним быстрые кнопки-пресеты.
- В `Sheet` «Изменить план», если в плане есть выполненные задачи, под полем — информационный `Alert`: «Выполненное останется в плане: „…“ сохранит свои 1:30. Остальные 4:30 разделим заново…». Нижняя граница времени — сумма минут выполненных слотов.
- **Пресеты времени**: чипы «2:00», «4:00», «6:00», «8:00» — обычные кнопки, нажатие подставляет значение в `TimeInput`. Чип, совпадающий с текущим значением поля, подсвечен (`aria-pressed="true"`: фон `--color-accent-soft`, текст и обводка 1.5px `--color-accent`). Чип: высота 36px (зона 44px), `--radius-full`, обводка `--color-border`.
- Подписи полей — `--text-sm` medium, подсказки — `--text-xs` muted.

### TimeInput
Поле ввода длительности в формате `Ч:ММ`; в API уходит целым числом минут.
- Вид: высота 44px, ширина ~120px, фон `--color-surface-sunken`, `--radius-md`, текст `--text-lg` semibold, tabular-nums, по центру; placeholder «0:00»; справа мелкая подпись «ч:мм» `--text-xs` muted. Фокус — обводка 2px `--color-focus`.
- `inputmode="numeric"`, `aria-label` поля — подпись поля, `aria-describedby` — подсказка/ошибка.
- Разбор ввода: «2:30» → 150; «2» → 120 (целые часы); «230» без двоеточия → 2:30 (последние две цифры — минуты). Минуты 00–59. После потери фокуса значение нормализуется к виду `Ч:ММ` («2:5» → «2:05»).
- Ограничения для плана дня: от 0:15 до 16:00. Ошибка — обводка и текст подсказки `--color-danger`: «Введите время в формате ч:мм, например 2:30» / «Не больше 16:00», primary-кнопка формы disabled.
- Ограничения для задачи (`Task.TimeForExecution`): от 0:05 до 99:59. Пресеты «0:30», «1:00», «2:00», «4:00». В длинных формах задачи primary-кнопка **не** блокируется — ошибки показываются при потере фокуса и при отправке (см. `Field`).

Вес группы выбирается не степпером, а `WeightScale` (см. «Формы»).

### Sheet
Модальная панель. Варианты: обычный и `sheet--quick` (`QuickAddSheet`: на десктопе ширина `--size-quick-sheet`, прижат к верху — `sheet-backdrop--top`). Мобильный: выезжает снизу, `--radius-lg` сверху, «ручка» 36×4 `--color-border-strong`, фон `--color-surface-raised`. Десктоп: диалог 420px по центру. Подложка `rgba(10,12,20,.45)`. Заголовок `--text-lg` semibold + icon-кнопка «×». Внизу две кнопки поровну: secondary «Отмена» и primary-действие. Закрывается по подложке, «×», Esc; фокус заперт внутри, при закрытии возвращается на кнопку-вызов. `role="dialog" aria-modal="true"`.

### Badge
Небольшая pill-метка: `--text-xs` medium, фон `--color-surface-sunken`, текст `--color-text-muted`, `--radius-full`, padding `2px 8px`. Для статусов вроде «Прошедший день».

### SectionTitle
Заголовок списка внутри экрана: слева `h2` `--text-lg` semibold, справа ghost-кнопка или подпись `--text-sm` muted.

### Skeleton
Прямоугольники `--color-surface-sunken`, `--radius-sm`, с пульсацией opacity 1 → 0.5 (1.2 с). Повторяют форму реального контента (заголовок группы + 3 строки задач). `aria-busy="true"` на контейнере. При `prefers-reduced-motion` — без анимации.

### EmptyState
По центру области: иконка 48px в круге `--color-accent-soft`, заголовок `--text-lg` semibold, текст-подсказка `--text-md` muted (max 32ch), primary-кнопка действия. Отступы `--space-12` сверху.

### ErrorState
Как EmptyState, но иконка в круге `--color-danger-soft` цвета `--color-danger`, заголовок «Не удалось загрузить задачи», текст ошибки из `{"error": "..."}` мелко muted, secondary-кнопка «Повторить».

### Toast
Снизу по центру над `BottomNav` (десктоп — снизу справа), фон `--color-text`, текст `--color-bg`, `--radius-md`, `--shadow-lg`, 4 с. Может содержать ghost-действие («Повторить»). `role="status"`. Используется для ошибок фоновых действий (не удалось отметить задачу) и для подтверждений после перехода («Задача создана» + «Открыть», «Задача удалена»). На экранах с `ActionBar` Toast поднимается над панелью.

## Формы (экраны «Новая задача», «Задача», «Группы»)

### FormCard
Смысловой блок формы: фон `--color-surface`, `--radius-lg`, `--shadow-sm`, padding `--space-4`, поля внутри через `--space-4`. Заголовок блока (`form-card__title`) — `--text-md` semibold («Что сделать», «Срок и объём», «Группа»). Блоки идут столбцом через `--space-4` (класс `form`).

### Field, Input, Textarea
- `Field` — подпись (`field__label`, `--text-sm` medium) → контрол → подсказка/ошибка (`field__hint`, `--text-xs` muted), промежутки `--space-2`. Необязательное поле помечается в подписи: «Описание — необязательно» (`field__optional`, regular muted). Обязательные ничем не помечаются — их большинство.
- `Input`: высота 44px, фон `--color-surface-sunken`, без обводки, `--radius-md`, `--text-md`, padding `0 --space-3`; placeholder `--color-text-muted`; фокус — обводка 2px `--color-focus`.
- `Textarea`: то же, минимум 88px (3 строки), растёт по содержимому (`field-sizing: content`, во фронтенде — autosize), padding `--space-3`.
- Ошибка: обводка 2px `--color-danger` (`input--error`), `aria-invalid="true"`, текст ошибки в `field__hint--error` (`--color-danger`), связан через `aria-describedby`. Предупреждение (не блокирует отправку): `field__hint--warning`, `--color-warning`, с иконкой.
- Когда показывать ошибки: после потери фокуса полем и при попытке отправки; при исправлении ошибка исчезает сразу по вводу. При отправке с ошибками — фокус на первое ошибочное поле.
- Disabled (во время отправки): opacity 0.6.

### TitleInput
Название задачи, редактируемое «на месте» на экране «Задача»: выглядит как заголовок (`--text-xl` semibold, без фона). Hover — фон `--color-surface-sunken`, фокус — фон `--color-surface` + обводка 2px `--color-focus`. Многострочное (textarea без переноса по Enter: Enter снимает фокус). У выполненной задачи — цвет `--color-text-muted` (без зачёркивания: это не список).

### DeadlineField
Дедлайн = дата + время.
- Ряд из двух `Input`: `type="date"` (шире, 1.3fr) и `type="time"` (1fr). Нативные пикеры — они лучше всего работают на мобильных.
- Под ними — чипы-пресеты (как в `PlanForm`): «Сегодня, 21:00» (скрыт, если сейчас позже 20:00), «Завтра, 18:00», «Через 3 дня» (18:00), «Через неделю» (18:00). Чип, совпадающий с выбранным значением, подсвечен (`aria-pressed`).
- Если выбрана только дата — время по умолчанию 18:00.
- Под полем — живая расшифровка в формате `DeadlineLabel` + относительное время: «завтра, 10:00 — через 20 ч» (цвет по правилам `DeadlineLabel`, иконка `flag`). Пока поле пустое — подсказка «Не раньше чем через час».
- Валидация: обе части заполнены; дедлайн не раньше чем через 1 час от текущего момента (бэкенд считает приоритет по целым часам до дедлайна и отклоняет 0). Ошибка: «Дедлайн уже прошёл. Выберите время хотя бы на час позже текущего» / «Слишком близко: дедлайн должен быть хотя бы через час».
- `<fieldset>` с `<legend>` «Дедлайн»; у полей `aria-label` «Дата дедлайна» / «Время дедлайна».

### GroupPicker
Выбор группы задачи — чипы с одиночным выбором.
- Контейнер `role="radiogroup"`, чипы `role="radio"` + `aria-checked` (вид выбранного — как `aria-pressed` у `Chip`). Стрелки ←/→ переключают выбор (roving tabindex).
- Порядок: группы пользователя по `GroupPriority` ↓, затем по `Name`; потом «Без группы» (`groupId = 0`); последним — чип-действие «+ Новая группа» (`chip--add`: пунктирная обводка `--color-border-strong`, текст `--color-accent`, не является radio).
- Чип группы (`chip chip--weight w-N`): слева точка 8px цвета веса (`chip__dot`, `--w`), название, после него вес «×3» (`chip__weight`, `--text-xs` muted). Выбранный чип — в цветах своей ступени: фон `--w-soft`, обводка 1.5px `--w`, текст `--w-text` (вместо акцентного `--color-accent-soft`). `aria-label="Учёба, вес 3"`. «Без группы» — точка `--color-border-strong`.
- Длинные названия обрезаются многоточием на 24 символах (полное — в `title`).
- «+ Новая группа» открывает `Sheet` с `GroupForm`; после создания новая группа появляется в списке и сразу выбрана, фокус — на ней.
- Загрузка групп — 3 чипа-skeleton (`chip--skeleton`) + «Без группы» (доступен сразу). Ошибка загрузки — подсказка «Не удалось загрузить группы» + ghost-кнопка «Повторить»; «Без группы» и «+ Новая группа» остаются доступны.
- Под чипами — подсказка «Цвет и ×N — вес группы: он умножает приоритет задачи.» + ссылка «Управлять группами» (→ `/groups`).

### GroupForm
Форма группы в `Sheet` (создание и изменение), одна и та же на экранах «Новая задача», «Задача» и «Группы».
- `Input` «Название» (обязательное, 1–60 символов после trim, уникальное среди групп пользователя без учёта регистра и «ё/е»: «Группа «Учёба» уже есть»).
- `WeightScale` «Вес в приоритете» ×1…×10, по умолчанию ×1. Под ним — объяснение, меняющееся со значением: «×1 — как у задач без группы» / «Задачи группы будут в N раза важнее задач без группы» + с кем группа окажется на одной ступени («Встанет на одну ступень с „Работой“»). При изменении веса существующей группы: «Было ×3. … Приоритет N активных задач группы пересчитается — они поднимутся/опустятся в списке». В форме можно только поставить группу на ступень; вставка «между» с подъёмом остальных — только на лесенке экрана «Группы».
- Ошибка сервера — `Alert` над полями; Sheet не закрывается.
- Кнопки: «Отмена» / «Создать группу» или «Сохранить» (с состоянием загрузки).

### WeightScale
Выбор веса группы 1–10 в `GroupForm` — «мини-лесенка».
- Шапка: подпись поля слева, справа значение «×4» в плашке цвета ступени (`weight-scale__value`: фон `--w-soft`, обводка 1.5px `--w`, текст `--w-text`, `--text-lg` semibold).
- Трек (`weight-scale__track`, высота 72px): 10 столбиков на всю ширину, высота растёт с номером (8px + N×4.4px), каждый своего цвета `--color-weight-N`. Столбики ≤ выбранного — полный цвет, выше — opacity 0.28 («лесенка заполнена до этой ступени»). Выбранный — двойное кольцо (2px фон + 2px `--w`). Под столбиками — номера 1…10 (`--text-xs` muted, у выбранного `--w-text` semibold).
- Точки 6px `--color-text-muted` над столбиками — ступени, уже занятые другими группами; под треком — легенда «● уже заняты: ×4 Английский · ×2 Работа, Хобби · ×1 Дом, Спорт».
- Взаимодействие: весь трек — одна зона нажатия. Тап или перетаскивание пальцем/мышью выбирает столбик под курсором (`floor(x / ширина × 10) + 1`). Клавиатура: ←/↓ −1, →/↑ +1, Home ×1, End ×10.
- Семантика: трек — `role="slider"`, `tabindex="0"`, `aria-valuemin=1`, `aria-valuemax=10`, `aria-valuenow`, `aria-valuetext="×4, на одной ступени с Английский"`, `aria-labelledby` — подпись, `aria-describedby` — подсказка. Фокус — обводка 2px `--color-focus` со смещением 4px.
- Почему не 10 кнопок: на 360px ширины кнопка получилась бы ~30px — меньше минимальной зоны 44px. Один слайдер на всю ширину решает это.

### PercentSlider
Прогресс задачи (`PercentOfCompleting`).
- Строка: подпись «Выполнено» (`form-card__title`) слева, значение справа — «40%» `--text-xl` semibold, tabular-nums (`<output>`).
- `input type="range"` 0–100, шаг 5, высота зоны 44px; трек 8px `--radius-full`: заполненная часть `--color-accent`, остальное `--color-surface-sunken`; бегунок 24px, фон `--color-surface`, обводка 2px `--color-accent`, `--shadow-md`; фокус — дополнительное кольцо 6px `--color-accent-soft`. Заполнение задаётся CSS-переменной `--value`.
- Под треком — шаги «0% · 25% · 50% · 75% · 100%» (кнопки `step`, `--text-xs` muted, зона 44px; совпадающий с значением — `--color-accent` semibold, `aria-pressed`).
- Подсказка: «На 100% задача станет выполненной». Клавиатура: стрелки ±5, PageUp/PageDown ±25, Home/End.
- Disabled (задача выполнена): opacity 0.5 и подсказка «Чтобы изменить прогресс, верните задачу в работу».

### PriorityCard
Объясняет приоритет задачи — ненавязчиво: сначала результат, «почему» — по раскрытию.
- Карточка `--color-surface`, `--radius-lg`, `--shadow-sm`, слева полоска `PriorityIndicator` (цвет уровня; у выполненной — `--color-border`).
- Шапка: «Приоритет» (semibold) + `PriorityChip` с числом + справа место в очереди `--text-sm` muted: «1-я из 9 активных» (на экране создания — «встанет 2-й из 10»).
- Одна строка пояснения `--text-sm` muted: «Чем ближе дедлайн и больше осталось работы, тем выше задача в списке.»
- При несохранённых изменениях — плашка `priority-card__next` (фон `--color-accent-soft`, текст `--color-accent`): «После сохранения ≈ 12,6 → 2-я из 9». Значение считается на клиенте по той же формуле.
- `<details>` «Из чего складывается» (ghost-стиль, `--color-accent`, шеврон поворачивается). Внутри — столбик множителей: оператор (моно, muted) · название + пояснение `--text-xs` muted · значение (semibold, tabular-nums):
  `Вес группы «Учёба» 3` → `× Время на выполнение 3:00 → 180 мин` → `÷ Часов до дедлайна 20` → `× Осталось сделать (выполнено 40%) 0,6` → `= Приоритет 16,2`. Ниже мелко моноширинным: `Pt = Pg × Te ÷ Tl × %in`.
- Раскрытость запоминается в `localStorage` (`tm.priorityExplained`), по умолчанию свёрнуто.
- Выполненная задача: вместо чипа — `Badge` «0», текст «Выполненные задачи не участвуют в очереди и стоят внизу своей группы», без раскрытия.

### StatusBanner
Плашка «Выполнена» на экране задачи: фон `--color-success-soft`, `--radius-lg`, иконка `check-circle` `--color-success`, заголовок semibold, подпись `--text-xs` muted («Отмечена сегодня, 11:05» по `UpdatedAt`), справа secondary-кнопка «Вернуть в работу» (иконка `undo`). На узком экране кнопка переносится под текст. `role="status"`.
У активной задачи на этом месте — secondary-кнопка на всю ширину «✓ Отметить выполненной» (иконка `check` цвета `--color-success`).

### ActionBar
Липкая панель действий формы.
- Мобильный: `position: fixed` внизу экрана (вместо `BottomNav`), фон `--color-surface-raised`, тень `--shadow-nav`, padding `--space-3 --space-4` + safe-area; кнопки делят ширину поровну: secondary «Отмена»/«Отменить» и primary.
- Десктоп (≥ 960px): `position: sticky` внизу колонки контента, `--radius-lg`, `--shadow-lg`; кнопки по ширине текста, прижаты вправо; слева — подпись `--text-sm` muted («Есть несохранённые изменения»).
- На «Новой задаче» видна всегда; на «Задаче» — только когда форма изменена (появляется с анимацией снизу, `--duration-normal`).

### Alert
Сообщение об ошибке внутри формы или Sheet (в отличие от `ErrorState`, который заменяет весь экран): фон `--color-danger-soft`, `--radius-md`, иконка `alert-triangle` `--color-danger`, заголовок semibold `--text-sm` («Не удалось создать задачу») и текст ошибки muted. `role="alert"`, при появлении получает фокус (`tabindex="-1"`) и прокручивается в видимую область.
**Информационный вариант** `alert--info` (не ошибка, например «Выполненное останется в плане» в Sheet плана, «Браузер не умеет присылать уведомления»): фон `--color-accent-soft`, иконка `info` `--color-accent`, без `role="alert"` и без перехвата фокуса.
**Предупреждение** `alert--warning` (действие нужно сделать вне приложения: «Уведомления заблокированы»): фон `--color-warning-soft`, иконка `alert-triangle` `--color-warning`, без `role="alert"`.
Внутри `Alert` могут быть список шагов (`alert__steps`, `--text-sm` muted) и кнопки (`alert__actions`: secondary высотой 36px, зона 44px).
**Исключение для `QuickAddSheet`:** `Alert` не забирает фокус — иначе на телефоне закроется клавиатура; он объявляется через `role="alert"`.

### ConfirmSheet
`Sheet` для подтверждения необратимого действия: `role="alertdialog"`, заголовок-вопрос («Удалить задачу?»), текст-последствие `--color-text-muted` (что именно пропадёт и что будет с зависимыми данными), кнопки «Отмена» (secondary, получает фокус по умолчанию) и danger-кнопка с глаголом («Удалить», «Удалить группу», «Выйти без сохранения»). Во время запроса — состояние загрузки на danger-кнопке, Sheet не закрывается по подложке.

### GroupLadder (экран «Группы»)
Лесенка из 10 ступеней: ×10 сверху, ×1 снизу. Группы стоят на ступенях, на одной ступени может быть несколько групп.
- Контейнер `ladder` (`<ol>`): карточка `--color-surface`, `--radius-lg`, `--shadow-sm`, padding `--space-2` 0.
- **Ступень** (`ladder__step .w-N`, `style="--n: N"`): сетка из двух колонок. «Перила» (76px; десктоп 112px) — цветная полоса-ступень высотой 10px, её ширина растёт с весом (`6px + N × 3.4px`, десктоп `10px + N × 6px`), и «×N» (`--text-xs` semibold). Справа — карточки групп с переносом (`gap --space-2`).
  - Занятая (`--busy`): высота ≥ 56px, полоса в полном цвете, «×N» цветом `--w-text`.
  - Пустая: высота 36px, полоса с opacity 0.35, «×N» muted. Подпись «свободно» видна только во время переноса.
  - Все 10 ступеней видны всегда: раскладка не прыгает при старте перетаскивания.
- **LadderGroup** (`ladder-group .w-N`): высота ≥ 44px, `--radius-md`, фон `--w-soft`, слева полоска 3px `--w`.
  - Основная часть — кнопка «Изменить» (открывает `Sheet` с `GroupForm`): название (`--text-sm` medium, многоточие после ~22 символов) и мета «4 задачи · 1 выполнена» (`--text-xs`, `--w-text`). `aria-label="Учёба, вес 3, 4 задачи, 1 выполнена. Изменить"`.
  - Справа — ручка ⋮⋮ (`ladder-group__handle`, иконка `grip`, 36px и зона 44px, `touch-action: none`, курсор `grab`): перетаскивание, а короткий тап / Enter — режим размещения. `aria-label="Переместить «Учёба» на другую ступень"`.
  - Состояния: `--lifted` (перетаскивается: `--shadow-lg`, поворот −1,5°, scale 1.03), `--ghost` (прежнее место: opacity 0.35, пунктир `--w`), `--moving` (группа в режиме размещения: обводка 2px `--color-focus`), `--pending` (сохраняется: opacity 0.6), предпросмотр сдвига «→ ×4» в мета-строке (`ladder-group__shift`, semibold).
  - «Без группы» (`--static`): не кнопка, без ручки, фон `--color-surface-sunken`, пунктир `--color-border-strong`, всегда на ×1.
- **Цели переноса**:
  - ступень — при перетаскивании фон строки `--color-accent-soft` (`ladder__step--hot`); в режиме размещения кнопка `ladder__place` («Поставить на ×N» / «Сюда, рядом»: высота 36px, зона 44px, пунктир 1.5px `--w`, текст `--w-text`);
  - промежуток между двумя **занятыми** ступенями (`ladder__gap`) — при перетаскивании линия 4px `--color-accent` с кольцом `--color-accent-soft` и плашкой «Вставить на ×3» (`--color-accent`, текст `--color-text-inverse`); в режиме размещения — кнопка на всю ширину (`ladder__gap-btn`, 44px, `--text-xs` `--color-accent`) с последствиями: «Между ×2 и ×3: встанет на ×3, поднимутся: Учёба ×4, Английский ×5». Если свободной ступени нет — disabled, «нет свободной ступени».
- **Правило вставки** (подъём цепочкой до первой свободной ступени, иначе опускание, иначе запрет) и API — `design/screens/groups.md`.
- Модификаторы контейнера: `ladder--dragging`, `ladder--placing`.

### PlaceBanner
Липкая плашка над лесенкой в режиме размещения: фон `--color-accent-soft`, текст `--color-accent` `--text-sm` medium, `--radius-md`, прилипает под `PageHeader` (top 60px). Текст «Куда поставить «Спорт»? Выберите ступень или место между группами» + ghost «Отмена». `role="status"`.

### WeightTile
Квадрат 40×40, `--radius-md`, в цветах ступени: фон `--w-soft`, текст `--w-text` semibold tabular-nums «×3», слева внутренняя полоска 3px `--w`. Нейтральный вариант (`weight-tile--base`) — фон `--color-surface-sunken`, текст `--color-text-muted`. Сейчас на экранах не используется (строки групп заменены лесенкой); оставлен для компактных списков групп.

### MetaNote
Служебная строка по центру `--text-xs` muted: «Создана 20 сентября, 09:12 · изменена вчера, 21:40».

## Быстрый ввод (экран-лист «Быстрая задача»)

### QuickAddSheet
Нижний лист для ввода задачи в одно действие: название + Enter. Полная спецификация — `design/screens/quick-add.md`.
- Основа — `Sheet` в варианте `sheet--quick`. Шапка (`quick-add__head`): «Новая задача» `--text-lg` semibold, ghost «Подробнее →» (переход на `/tasks/new` с параметрами), icon-кнопка «×». Нижних кнопок «Отмена / Действие» нет: действие «Добавить» стоит в нижней строке рядом с группой.
- Сверху вниз: плашка (одна: `Notice` офлайн > `Alert` ошибка > строка успеха) → название (`Input` 48px, `--text-lg` medium) → `ChipRow` «Дедлайн» → `ChipRow` «Время» → (`ChipRow` «Группа», если раскрыта) → строка предпросмотра (`quick-add__preview`: `PriorityIndicator`-чип + «встанет 5-й из 12», `--text-xs` muted; на десктопе ещё подсказка `kbd`) → низ (`quick-add__foot`): `GroupToggle` слева, primary «Добавить» справа (min-width 128px).
- Раскрытие «Другое…» (`quick-add__extra`, отступ 28px — под иконкой ряда): `DeadlineField` без чипов или `TimeInput`.
- Строка успеха (`quick-add__status`): фон `--color-success-soft`, иконка `check-circle` `--color-success`, текст `--text-sm` в одну строку с многоточием («**5-я из 12** — «…»»), ghost «Открыть». `role="status"`.
- Поведение: тап по чипам не уводит фокус из названия (`pointerdown` → `preventDefault`), во время отправки поле `readOnly`, а не `disabled` — экранная клавиатура не закрывается. После успеха лист не закрывается, название очищается (серия задач).
- Десктоп: диалог `--size-quick-sheet` (520px), прижат к верху (`padding-top: 12vh`), чипы переносятся.

### ChipRow
Ряд чипов с одиночным выбором в одну строку — компактная замена блока «подпись + чипы».
- Сетка: иконка ряда 24px (`chip-row__lead`, 16px `--color-text-muted`: `flag`, `clock`, `folder`) и прокручиваемая область (`chip-row__scroll`). Подпись ряда — `legend.visually-hidden` и `aria-label` у `role="radiogroup"`.
- Мобильный: без переноса, горизонтальная прокрутка без полосы. Ряд заходит под правый край листа (`margin-right: -16px`), справа затухание 32px (`mask-image`). Когда ряд прокручен до конца, затухание снимается (`chip-row--end`). Выбранный чип при показе прокручивается в зону видимости.
- Десктоп (≥ 960px): чипы переносятся, прокрутки и затухания нет.
- Чипы — `Chip` с `role="radio"` + `aria-checked` (вид выбранного — как у `aria-pressed`), стрелки ←/→ (roving tabindex). Вертикальная зона нажатия 44px сохраняется за счёт padding 4px у прокручиваемой области.
- Чип «Другое…» (`chip--other`): `role="radio"` + `aria-expanded` + `aria-controls`. Раскрывает поле под рядом. Когда в поле введено валидное значение, подпись чипа заменяется значением («пт, 9 окт, 12:00», «3:30»).

### GroupToggle
Компактный показ текущей группы в `QuickAddSheet` — кнопка-чип, которая раскрывает `ChipRow` с `GroupPicker`.
- Вид: `chip` в цветах ступени выбранной группы (как выбранный `chip--weight`: фон `--w-soft`, обводка 1.5px `--w`, текст `--w-text`); для «Без группы» — `--color-surface-sunken`, обводка `--color-border-strong`. Внутри: точка 8px, название (многоточие, max-width 62% строки), «×3», шеврон 16px, который поворачивается при раскрытии.
- `aria-expanded`, `aria-controls` — ряд групп; `aria-label="Группа: Учёба, вес 3. Сменить"`.
- Загрузка групп — `chip--skeleton` шириной 96px.

### Notice
Нейтральная плашка о состоянии среды, не об ошибке: «Нет сети». Фон `--color-surface-sunken`, `--radius-md`, иконка 16px `--color-text-muted` (`wifi-off`), текст `--text-sm` с жирным началом («**Нет сети.** …»). `role="status"`.

## Настройки (экран «Профиль»)

### ProfileCard
Карточка пользователя вверху профиля: `--color-surface`, `--radius-lg`, `--shadow-sm`, padding `--space-3 --space-4`. Аватар 48px (как `AvatarButton`, без кнопки), имя semibold («Пользователь #1»), подпись `--text-sm` muted («Вход и синхронизация появятся позже»).

### SettingsCard
Список настроек в одной карточке (`<ul class="settings">`): фон `--color-surface`, `--radius-lg`, `--shadow-sm`, строки разделены линией `--color-border`.
- Строка (`settings__row`): сетка `24px | 1fr | auto` — иконка (`--color-text-muted`), название (medium) и подпись под ним (`--text-sm` muted; успешное состояние — `settings__sub--ok`, `--color-success`), справа `Switch`. Высота ≥ 56px.
- Параметр настройки (`settings__extra`): второй ряд строки под названием (колонки 2–3): подпись `--text-sm` muted + `Input type="time"` (`input--time`, 120px) или чипы. Показывается, только когда настройка включена (`settings__row--off` его скрывает); значение не сбрасывается.
- Пояснение под строкой (`settings__notice`): `Alert` или подсказка `field__hint`.
- Низ карточки (`settings__foot`): secondary-кнопка и подсказка под ней.
- Вся строка — не кнопка: переключается только `Switch` (название связано через `aria-labelledby`).

### Switch
Переключатель вкл./выкл. для настроек, которые применяются сразу (без кнопки «Сохранить»).
- Трек `--size-switch-w` × `--size-switch-h` (48×28), `--radius-full`. Выкл.: фон `--color-surface-sunken`, обводка 1.5px `--color-border-strong` (3:1), бегунок 20px `--color-border-strong` слева. Вкл.: фон `--color-accent`, бегунок `--color-text-inverse` справа. Анимация бегунка `--duration-normal`.
- Зона нажатия 56×44. `<button role="switch" aria-checked>`, подпись через `aria-labelledby`, пояснение через `aria-describedby`. Фокус — кольцо 2px `--color-focus` вокруг трека.
- Ожидание (`switch--pending`, `aria-busy="true"`): бегунок пульсирует, пока идёт асинхронное действие (запрос разрешения браузера). Disabled — opacity 0.5, `not-allowed`.
- Ошибка сохранения — откат положения и `Toast` «Не удалось сохранить настройку» + «Повторить».

## Форматы

| Что | Правило | Примеры |
|---|---|---|
| Длительность (`Task.TimeForExecution`, `Day.TimeForTasks`, хранятся в минутах) | показ и ввод — `Ч:ММ`: часы без ведущего нуля, минуты всегда двумя цифрами. Для скринридеров — словами | «0:45», «2:00», «2:30», «7:00»; `aria-label="2 часа 30 минут"` |
| Дедлайн в будущем | сегодня → «сегодня, ЧЧ:ММ»; завтра → «завтра, ЧЧ:ММ»; 2–6 дней → «через N дней»; дальше → «12 окт» (с годом, если не текущий) | «сегодня, 18:00», «через 3 дня» |
| Дедлайн прошёл | «просрочено на N мин/ч/дн» (это относительное время, а не длительность — формат `Ч:ММ` здесь не применяется) | «просрочено на 2 ч» |
| Дата дня | «Сегодня, 24 сентября» / «Завтра, 25 сентября» / «Пятница, 26 сентября» | |
| Приоритет | 1 знак после запятой, запятая | «7,5», «0,4» |
| Количество | с согласованием: «1 задача», «3 задачи», «5 задач» | |
| Дедлайн в поле ввода (расшифровка) | `DeadlineLabel` + « — через N мин/ч/дн» | «завтра, 10:00 — через 20 ч», «через 3 дня — пт, 27 сентября, 18:00» |
| Служебные даты (`CreatedAt`, `UpdatedAt`) | сегодня/вчера → «сегодня, 11:05» / «вчера, 21:40»; иначе «20 сентября, 09:12» (с годом, если не текущий) | |
| Место в очереди | порядковое числительное в женском роде (задача) | «1-я из 9 активных», «встанет 2-й из 10» |
| Вес группы | «×N» + цвет ступени `--color-weight-N` | «×3» |
| Время задачи в плане дня (`DayTask.Minutes`) | `Ч:ММ` + «сегодня»; кратно 5 мин, не меньше 0:15 | «1:25 сегодня», «0:15 сегодня» |

Время — в локальном часовом поясе браузера; API отдаёт RFC3339.
