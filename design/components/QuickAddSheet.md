# QuickAddSheet
Bottom sheet to enter a task in one action: name + Enter. Screen summary: [quick-add](../screens/quick-add.md); defaults/draft rules: [quick-add-rules](../rules/quick-add-rules.md).
- Base: [Sheet](Sheet.md) variant `sheet--quick`. Header (`quick-add__head`): "Новая задача" `--text-lg` semibold, ghost "Подробнее →" (to `/tasks/new` with params), icon "×". No bottom "Отмена / Действие" buttons: "Добавить" sits in the bottom row next to the group.
- Top to bottom: handle (mobile only) -> banner (at most one: [Notice](Notice.md) offline > [Alert](Alert.md) error > success line) -> name `Input` (48px, `--text-lg` medium, placeholder "Что нужно сделать?", `autofocus`, `enterkeyhint="send"`, `maxlength=200`, `autocapitalize="sentences"`) -> [ChipRow](ChipRow.md) "Дедлайн" (icon `flag`) -> ChipRow "Время на выполнение" (icon `clock`) -> ChipRow "Группа" (icon `folder`, only when [GroupToggle](GroupToggle.md) is expanded) -> preview line (`quick-add__preview`: priority chip + "встанет 5-й из 12", `--text-xs` muted; desktop also hint "· Enter добавить · Esc закрыть" with `kbd`) -> foot (`quick-add__foot`): GroupToggle left, primary "Добавить" right (min-width 128px).
- "Другое…" expansion (`quick-add__extra`, 28px indent under the row icon): [DeadlineField](DeadlineField.md) without chips, or [TimeInput](TimeInput.md).
- Success line (`quick-add__status`): bg `--color-success-soft`, icon `check-circle` `--color-success`, `--text-sm` one line with ellipsis ("**5-я из 12** — «…»"), ghost "Открыть". `role="status"`. Next success replaces it.
- Behaviour: tap on chips must not move focus out of the name (`onPointerDown={e => e.preventDefault()}`); exception: "Другое…" moves focus into the date field / TimeInput. While sending the name is `readOnly`, not `disabled` (keeps the on-screen keyboard). After success the sheet stays open, name cleared (series). Tab moves between rows, arrows inside a row (roving tabindex).
- Keyboard-aware: `web/index.html` viewport `interactive-widget=resizes-content`; fallback `visualViewport.resize` and lift the sheet by `innerHeight - visualViewport.height`. Collapsed height ~310px; with two rows open it scrolls inside: `max-height: calc(100dvh - 24px)`.
- Desktop: dialog `--size-quick-sheet` (520px), top-pinned (`padding-top: 12vh`), chips wrap. `prefers-reduced-motion`: appears by opacity only.
