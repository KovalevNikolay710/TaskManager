# DeadlineLabel
Deadline text per [formats](../foundations/formats.md). Colour:
- overdue (`DeadLine < now`): `--color-danger`, medium, "просрочено на 3 ч";
- < 24 hours: `--color-warning`, medium;
- otherwise `--color-text-muted`.
Always with a calendar/flag icon — colour is never the only signal.
