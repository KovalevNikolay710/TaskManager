# PriorityCard
Explains task priority unobtrusively: result first, "why" on expand.
- Card `--color-surface`, `--radius-lg`, `--shadow-sm`, left bar of [PriorityIndicator](PriorityIndicator.md) (level colour; completed `--color-border`).
- Header: "Приоритет" (semibold) + priority chip with number + queue place right (`--text-sm` muted): "1-я из 9 активных" (on new-task: "встанет 2-й из 10").
- One explanation line `--text-sm` muted: "Чем ближе дедлайн и больше осталось работы, тем выше задача в списке." On new-task the text depends on place: 1st "Задача окажется первой в списке: срок близко, а работы много."; top third "Задача окажется среди самых срочных."; else "Срок позволяет: задача встанет ближе к концу списка."; inputs incomplete: "Укажите дедлайн и время на выполнение — покажем, каким по счёту задача встанет в списке."
- Unsaved changes: note `priority-card__next` (bg `--color-accent-soft`, text `--color-accent`): "После сохранения ≈ 12,6 → 2-я из 9", computed on the client by the same formula.
- `<details>` "Из чего складывается" (ghost style, `--color-accent`, chevron rotates). Inside, a column of factors: operator (mono, muted) · name + explanation `--text-xs` muted · value (semibold, tabular-nums): `Вес группы «Учёба» 3` -> `× Время на выполнение 3:00 → 180 мин` -> `÷ Часов до дедлайна 20` -> `× Осталось сделать (выполнено 40%) 0,6` -> `= Приоритет 16,2`. Below, small mono: `Pt = Pg × Te ÷ Tl × %in`. Use server values of `Pg/Te/Tl` so the product matches `Priority`; `Tl` caption "на момент расчёта, <UpdatedAt>". Expanded state in `localStorage` `tm.priorityExplained`, default collapsed.
- Completed task: [Badge](Badge.md) "0" instead of chip, text "Выполненные задачи не участвуют в очереди и стоят внизу своей группы", no expand.
- Preview maths (new-task): `Pg` = group weight (no group: 1); `Te` minutes; `Tl = floor((deadline - now) / 1 h)`; `%in = 1`; place = `1 + count(active with Priority > Pt)` of `active + 1`; level relative to `max(Priority of active, Pt)`. Recomputed on every change and once a minute.
