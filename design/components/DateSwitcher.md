# DateSwitcher
Row: icon button "‹" — date — icon button "›". Date "Сегодня, 24 сентября" (`--text-md` semibold); below it weekday (`--text-sm` muted) unless the date is today/tomorrow/yesterday. Arrows go to the previous/next existing `Day`; if there is none the arrow is disabled (so "›" is disabled on today without future days).
