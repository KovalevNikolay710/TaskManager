# Icons
Line icons 24px, stroke 1.75, `currentColor` (Lucide/Feather level). Used: `calendar` (День), `list-checks` (Все задачи), `search`, `x`, `plus`, `clock` (duration), `flag` (deadline), `zap` (priority), `chevron-down/left/right`, `alert-triangle`, `refresh-cw`, `inbox` (empty), `folder` (groups), `minus`, `check`, `check-circle` (done), `undo` (return to work), `trash-2` (delete), `arrow-right`, `grip-vertical` (drag handle ⋮⋮), `info` (info Alert, DayChart hints), `sun` / `coffee` (day empty states), `sliders` ("Изменить план"), `bell` (push), `bell-off` (quiet hours), `moon` (evening reminder), `send` (test notification), `wifi-off` (offline).

## App icon (PWA)
Manifest and notification icons, `theme_color` / `background_color`, `name` and `short_name`: `design/icons/README.md` (`icon.svg`, `icon-maskable.svg`, `badge.svg`).
